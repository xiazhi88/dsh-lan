直连你自己 Mac 上的 dsh-pocket 端口，不经过任何中转服务器。

连接你的 Mac

填 dsh-pocket 的入口地址。不确定？在 Mac 上打开 设置 → 手机访问，复制二维码下面那串链接。

地址形如 http://192.168.x.x:3081。 同一 WiFi 用局域网地址最快；不在同一网络时用 Tailscale 地址 100.x.x.x:3081。

排查清单

  • Mac 上 dsh web 是否在运行（终端里能看到 http://127.0.0.1:3080）
  • 手机和 Mac 是否在同一 WiFi / 同一 Tailscale 网络
  • Mac 设置页「手机访问」里的局域网访问开关是否开着
  • 地址里的端口是不是 3081（不是 3080）
